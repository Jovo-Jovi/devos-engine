### Prompt (canonical)

Create the engine repository's skeleton and copy the Dev OS method — exactly as it is in the Tower at the pinned
commit — into `payload/files/`, with a manifest that `install` and `upgrade` will later trust. **Nothing in the method
changes in this task:** E01 is a verbatim extraction. Rules for the whole task: zero dependencies; ES modules (`.mjs`);
Node built-ins only; `node:path` for every path (Windows and Linux), POSIX `/` inside the manifest; child processes
with `execFileSync`/`spawnSync` and no shell; every generated file deterministic, UTF-8, LF, ending in one newline.

#### Preconditions — HALT if any fails

- P1. `git status --porcelain` prints nothing. `git log --oneline` prints exactly one line, ending `B0: engine bootstrap`.
- P2. `node --version` is v22 or later.
- P3. `git -C ../devos-sources/tower rev-parse HEAD` prints `a49ca6db268b98d6558077bf3e95b8ae759d91b3` and
  `git -C ../devos-sources/pilot rev-parse HEAD` prints `4ccbef799546315a491da86f4e3676ba46d8fa51`.
- P4. None of these exist: `package.json`, `LICENSE`, `bin/`, `lib/`, `payload/`, `tools/`, `test/`, `dev/sources/`.

#### Steps

- **S1 — `package.json`.** Exactly these keys: `name` `devos-engine`, `version` `0.1.0`, `private` `true`, `type`
  `module`, `description` `"DEV_OS Engine — guided onboarding and an automated Cursor ⇄ Claude development cycle"`,
  `bin` `{ "devos": "bin/devos.mjs" }`, `engines` `{ "node": ">=22" }`, `files` `["bin/", "lib/", "payload/",
  "LICENSE", "README.md"]`, `scripts` `{ "test": "node --test \"test/*.test.mjs\"", "manifest": "node
  tools/build-manifest.mjs", "manifest:check": "node tools/build-manifest.mjs --check" }`. No `dependencies`, no
  `devDependencies`.
- **S2 — `LICENSE`.** Two lines: `Copyright (c) 2026 Jovo-Jovi. All rights reserved.` and `No license is granted
  until this file is replaced by the license chosen under decision D-E4.`
- **S3 — `tools/sources.mjs`** exports:
  - `TOWER = { repo: "Jovo-Jovi/devos-control-tower", commit: "a49ca6db268b98d6558077bf3e95b8ae759d91b3" }` and
    `PILOT = { repo: "Jovo-Jovi/devos-pilot", commit: "4ccbef799546315a491da86f4e3676ba46d8fa51" }`;
  - `METHOD_PATHS` = `scripts/devos`, `scripts/guards`, `devos`, `.github/workflows`, `.github/ISSUE_TEMPLATE`,
    `.cursor`, `.claude`, `docs/method/DEV_OS_V2_REVIEWER.md`, `docs/method/AUTOMATION.md`,
    `docs/method/FULLSTACK_MODULE.md`, `docs/method/PRECEDENTS.md`, `.gitignore`, `.gitattributes`;
  - `REFERENCE` = Tower `devos.config.json`, `CLAUDE.md`, `AGENTS.md`, `SETUP.md` → `dev/sources/tower/<same name>`;
    pilot `devos/setup.json` → `dev/sources/pilot/devos/setup.json`.
- **S4 — `lib/paths.mjs`** exports `toStored(installed)` and `toInstalled(stored)`. A path segment that starts with
  `.` is stored as `dot-` + the rest (`.github/workflows/ci.yml` ↔ `dot-github/workflows/ci.yml`, `.gitignore` ↔
  `dot-gitignore`). `toStored` throws on an installed segment that already starts with `dot-`; both take and return
  POSIX paths.
- **S5 — `tools/extract.mjs --tower <dir> --pilot <dir>`.** Exits 2 with a clear message unless both `HEAD`s equal
  `TOWER.commit` and `PILOT.commit`. Lists the Tower's **tracked** files with `git -C <tower> ls-files -z --
  <METHOD_PATHS>` (untracked or ignored files never enter). Copies each to `payload/files/<toStored(path)>`, converting
  CRLF to LF; HALT-worthy error if a file contains a NUL byte. Copies `REFERENCE` the same way. Removes any file under
  `payload/files/` that is not in the list. Prints exactly `copied 103 method files, 5 reference files`.
- **S6 — `tools/build-manifest.mjs`** writes `payload/manifest.json`:
  `{ "engine_version": <package.json version>, "source": { "repo": TOWER.repo, "commit": TOWER.commit },
  "files": [ { "path": <installed POSIX path>, "stored": <path under payload/files>, "sha256": <hex of the
  LF-normalized bytes>, "owner": "engine" } ] }`, files sorted by `path` in code-point order,
  `JSON.stringify(m, null, 2) + "\n"`. Prints `manifest written (103 files)`. With `--check` it builds in memory and
  compares: equal → prints `manifest up to date (103 files)`, exit 0; different → prints the first differing path, exit 1.
- **S7 — `tools/verify-source.mjs --tower <dir>`.** For every manifest entry, hashes `<dir>/<path>` the same way and
  compares; also compares the set of manifest paths with the Tower's `git ls-files` list of S5. All equal → prints
  `103 files identical to Jovo-Jovi/devos-control-tower@a49ca6d`, exit 0. Otherwise lists each mismatch, missing or
  extra path and exits 1.
- **S8 — `tools/find-specifics.mjs`** scans every file under `payload/files/` (LF-normalized, split on `\n`) for lines
  matching any of `/tower/i`, `/\bpilot\b/i`, `/\bADR-0\d\d\b/`, `/Jovo-Jovi/` and writes `dev/E01-specifics.md`:
  a title line `# Tower- and pilot-specific lines in the payload (input for E03)`, a table
  `| Installed path | Line | Text |` sorted by path then line (text trimmed to 120 characters, `|` escaped), and a last
  line `Total: <lines> lines in <files> files`.
- **S9 — `tools/stage.mjs <dir>`.** Copies every manifest entry to `<dir>/<path>` (installed names). Refuses a
  directory that exists and is not empty (exit 2). Prints `staged 103 files into <dir>`. Later tasks use it to run the
  payload's own scripts and guards in a scratch folder.
- **S10 — `bin/devos.mjs`** with `#!/usr/bin/env node`. `--version` or `-v` prints `devos 0.1.0` (read from
  `package.json` next to it, through `import.meta.url`), exit 0. No arguments or any other argument prints
  `devos 0.1.0 — commands arrive in E04` and exits 2.
- **S11 — Tests** in `test/` (`node:test`, `node:assert/strict`, nothing else):
  `paths.test.mjs` (five round trips, the throw), `manifest.test.mjs` (two in-memory builds are deep-equal; 103
  entries; sorted; no `\` in any path; every `stored` file exists and its hash matches; `engine_version` equals
  `package.json`), `stage.test.mjs` (stages into a `fs.mkdtempSync` folder: 103 files, `.github/workflows/devos-cycle.yml`
  and `.claude/settings.json` exist with the stored bytes; a second stage into the same folder exits 2),
  `version.test.mjs` (spawns `node bin/devos.mjs --version` → `devos 0.1.0\n`).
- **S12 — Run, in order:** `node tools/extract.mjs --tower ../devos-sources/tower --pilot ../devos-sources/pilot`,
  `node tools/build-manifest.mjs`, `node tools/find-specifics.mjs`. In `README.md` replace the line that starts with
  `Status:` by `Status: E01 — method extracted verbatim (103 files) · engine 0.1.0`.
- **S13 — Report** `dev/reports/E01.md`: `## Attempt 1`, STATUS (DONE or HALT), the files you created, then every
  Done-when command with its verbatim output.
