### Prompt (canonical)

`devos init <folder>` takes a developer from an empty folder to an approved blueprint, in this order:
1. it checks the machine;
2. it shows the contract and continues only on a typed `accept`;
3. it asks what it cannot infer;
4. it installs the method;
5. Claude Code writes the documents and fence T01 headless;
6. `guard:phases` and `guard:naming` must pass;
7. the developer approves or asks for changes.

The GitHub repository, secrets and the first cycle are E07. **Before acceptance nothing is written or sent (D-E3).**
`init` runs no git and no `gh` besides doctor's `gh --version`.

The three texts in `dev/fences/E06/` are exact. Copy them byte for byte; do not reword them.

#### Steps

- **S1 — The contract.** Copy `dev/fences/E06/CONTRACT.md` to `payload/contract/CONTRACT.md`. It stays outside
  `payload/files/`: it is shown, not installed. `lib/contract.mjs` exports:
  - `CONTRACT_VERSION = "0-draft"`;
  - `contractText()`, which reads that file through `engineRoot()`.
- **S2 — `lib/which.mjs`.** `run()` also passes `options.input` (stdin) through. Its `maxBuffer` is 64 MiB.
  Nothing else changes.
- **S3 — `lib/install.mjs`.** Split the command into `installInto(folder, key, { hold = [] })`, which returns
  `{ code, held }`.
  - A path in `hold` is not written. Its LF bytes are returned in `held`, but the lock still lists it.
  - `installCommand` calls `installInto` with no hold, and its output and exit codes are unchanged.
  - Also export the key rule `KEY_RE` and `keyFromName(name)`. `keyFromName` works as follows:
    - uppercase the name;
    - turn every run of characters outside `A-Z0-9` into `-`;
    - trim `-` at both ends;
    - prefix `P-` if the result does not start with a letter;
    - cut it to 32 characters and trim any trailing `-`.

    Examples: `Demo Shop` → `DEMO-SHOP`, `42 things!` → `P-42-THINGS`.
- **S4 — `lib/init.mjs`, `devos init [folder]`** (async; `bin/devos.mjs` awaits it). Read stdin one line at a time
  with `node:readline`, so typed and piped input behave the same. If input ends before step 9, print
  `devos: input ended before setup finished`; that exit is 1, and anything already written stays.
  1. **Folder.** Resolve it (the default is the current directory). If it exists and is not empty, print `devos: <folder>
     is not empty; devos init starts from an empty folder` and exit 1.
  2. **Doctor.** If `doctorCommand()` is not 0, exit 1. If `which("claude")` is null, print `devos: claude is not
     installed. Install Claude Code, then run: claude setup-token` and exit 1.
  3. **Contract.** Print `contractText()`, then the prompt `Type accept to continue: `. Only the line `accept`
     (trimmed, any case) continues. Anything else prints `devos: contract declined — nothing was written or sent` and
     exits 1. Up to this step the folder is never created.
  4. **Questions.** Ask them in this order. The default is shown in `[ ]`, and an empty line takes it. An invalid
     answer asks again; the third invalid answer prints `devos: no valid answer for <question>` and exits 1.
     1. `Project name:` required;
     2. `One-paragraph brief:` required;
     3. `Who uses it:` required;
     4. `Does it store data? (yes/no) [no]:`
     5. `Sign-in (none/email/oauth) [none]:`
     6. `Languages, comma-separated [en]:` (each entry matches `^[a-z]{2}(-[A-Z]{2})?$`);
     7. `Deploy target (vercel/none) [vercel]:`
     8. `Repository visibility (private/public) [<profile visibility, else private>]:`
  5. **Install.** `mkdirSync(folder)`, then `installInto(folder, keyFromName(name), { hold: [".claude/settings.json"] })`.
     A non-zero code exits 1.
  6. **Answers.** Write `devos/answers.json` (2-space JSON, LF) with these keys, in this order:
     - `$comment` `"Your answers to devos init. The blueprint reads them; change them here and ask for changes."`
     - `name`, `key`, `brief`, `users`, `stores_data` (boolean), `sign_in`, `languages` (array), `deploy`, `visibility`
     - `contract_version` (`CONTRACT_VERSION`)
  7. **Blueprint rounds**, at most 5 in total.
     - **The call.** Each round runs `run("claude", args, { cwd: folder, input, timeout: 3600000 })`. The args are:
       - `-p --output-format json --permission-mode acceptEdits --max-turns 200`
       - `--allowedTools "Read,Glob,Grep,Write,Edit,WebFetch,WebSearch,Bash(node scripts/devos/config.mjs --write)"`
       - `--disallowedTools "Bash(git *),Bash(gh *),Bash(curl *),Bash(wget *),Bash(rm *)"`
       - from round 2 on, also `--continue`.
     - **Round 1 input** is the text of `<folder>/devos/prompts/blueprint.md`.
     - **Later round input** is `The developer asks for these changes:\n<text>\n\nApply them to the documents and fence
       T01, keeping every rule of devos/prompts/blueprint.md.`
     - **Output.** Print the `result` field of the JSON on stdout, or the raw stdout when it is not JSON.
     - **Failure.** If `claude` returns null or non-zero, print its stderr, then `devos: the blueprint failed; delete
       <folder> and run devos init again`, and exit 1.
  8. **Checks** after every round:
     - `docs/PHASES.md`, `docs/GLOSSARY.md` and `docs/fences/T01.md` exist;
     - `node scripts/guards/run-all.mjs --only phases,naming` (`process.execPath`, `cwd` = the folder) exits 0.

     If a check fails, the next round runs automatically. Its text is the list of missing files plus the guard
     output, and the developer is not asked.
  9. **Approval.** When the checks pass, print `Blueprint written:` and the files under `docs/` (sorted, POSIX, one
     per line). Then prompt `Type approve, or describe the changes you want: `. The answer `approve` (trimmed, any
     case) finishes; any other text becomes the next round. After round 5 without approval, print `devos: no approved
     blueprint after 5 rounds; the folder keeps the last one` and exit 1.
  10. **Finish.**
      - Write the held `.claude/settings.json`.
      - Print `devos init: blueprint approved in <folder>`, then `devos: next — the GitHub repository, secrets and the
        first cycle are the next part of setup (not in this version)`.
      - Exit 0.
