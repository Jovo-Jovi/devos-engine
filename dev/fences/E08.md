### Prompt (canonical)

Make design a written contract and every UI fence a checked specification.
- A project whose type has a web interface keeps `docs/DESIGN_SYSTEM.md` and `docs/design/UI_ACCEPTANCE.md`, written by the blueprint.
- Every open UI fence carries a `### Design specification`. Its states equal the fence's `- Screens:` names, and its criteria are rows of `UI_ACCEPTANCE.md`. A new guard fails the run otherwise.
- `docs/method/DESIGN_METHOD.md` states the lifecycle, the acceptance gate and the resource catalogue.

This is a method change, PR-50. The texts in `dev/fences/E08/` are exact: copy them byte for byte.
