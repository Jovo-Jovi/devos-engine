### Prompt (canonical)

Each tool may take the other role. Claude Code can build. Cursor can review, including with a GPT, Gemini or Grok
model, because the model is whatever the agent row names. The verdict of record stays the review file (PR-21): the
runner reads it and never writes `VERDICT:`. On a usage limit, after that agent's own accounts are exhausted, the
runner tries the next pool agent once. A Windows `.cmd` path that contains a space is quoted when `run()` starts it
through the shell. Codex CLI and Gemini CLI adapters are not this task.
