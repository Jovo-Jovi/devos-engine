    - **Codex.**
      - Read the JSONL lines.
      - `usage` sums `usage.input_tokens` and `usage.output_tokens` over the `turn.completed` events.
      - `is_error` is set when there is any `turn.failed` or `error` event.

        - the trimmed `lastText`;
        - the last `item.completed` whose `item.type` is `agent_message` (its `item.text`);
        - the last error message (`error.message` or `message`);
        - `""`.
    - **Gemini.**
      - `JSON.parse(rawText)`. If that fails, `is_error` is true and `result` is the last 2000 characters of the trimmed text.
      - `result` is `response ?? error.message ?? ""`. `is_error` is `Boolean(error) || typeof response !== "string"`.
      - `usage` sums `tokens.prompt` and `tokens.candidates` over `stats.models`.
  - **Command line.**
    - `args --tool --role --model --effort --last` prints each item of `cliArgs` followed by a NUL byte.
    - `normalize --tool --raw <f> --last <f> --out <f>` reads `<f>.stream.jsonl` if it exists, else `<f>`, and reads `--last` if it exists. It writes the object as one JSON line to `--out`. It may overwrite `--raw`.
