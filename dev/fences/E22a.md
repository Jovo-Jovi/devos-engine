- **FIX 1 — a finished run never breaks the next one.**
  - **The temp folder.** One function makes sure it exists: when it is gone, it is created again with `mkdtempSync` and mode 0700. `POST /api/plan` and `POST /api/start` call it before they write anything.
  - **A new plan after a run.** When `POST /api/plan` arrives after a `done`, it first clears `events`, sets `finished` to false and `unanswered` to null, and drops the held plan.
  - **Stop with nothing running.** `POST /api/stop` with no child answers 409 `{"error":"state"}` and emits nothing.
- **FIX 2 — no request can stop the server.**
  - **Bodies.** A body that parses to something other than a plain object (`null`, an array, a string or a number) answers 400:
    - `/api/plan`: `{ ok:false, errors:["The plan is not a JSON object."] }`;
    - `/api/answer`: `{ ok:false, errors:["The answer is not a JSON object."] }`.
  - **One `try`/`catch` around the whole request handler.**
    - On an error, answer 500 `{"error":"internal"}` when headers are not yet sent, and otherwise `res.destroy()`.
    - Never print the error's message or stack.
    - The server keeps serving.
- **FIX 3 — a file key never touches the disk.**
  - **`readFileKey(key, read, stdout)`** gains one case. When `read.interactive === true` and the trimmed line starts with `base64:`:
    - it decodes the rest in memory with `Buffer.from(rest, "base64").toString("utf8")`;
    - it checks the text with `JSON.parse`, and returns it;
    - on failure it prints `devos: <KEY>: the value given is not JSON` and asks again, as it does today.

    Otherwise `readFileKey` behaves byte for byte as today, so the terminal still takes a path.
  - **`/api/answer`.** For a file key, check that `value` decodes to JSON, as today. Then write `base64:<value>` and `\n` to the child's stdin. Remove the `key-<hex>.json` write; no key is ever written to a file.
- **FIX 4 — the token comes before the body.** The order of checks is Host, then Origin (non-GET), then the token.
  - The token is the `X-DEVOS-Token` header for `/api/`; `GET /` keeps its `?t=` check.
  - The body is read only after these checks. A request refused by them is answered after `req.resume()`, so its body is drained, never buffered.
- **FIX 5 — Stop ends the model.**
  - **POSIX.** `POST /api/stop` with a child:
    - sets `stopping`;
    - sends `process.kill(pid, "SIGINT")`;
    - starts an unref'd 2 s timer that calls `killPidTree(pid)` if the child has not closed. The child's `close` clears the timer.
  - **Windows.** Call `killPidTree(pid)` at once: `taskkill /T` must walk the tree while the child is alive.
  - **The answer and the event.** Stop answers 204 at once. The `done` event comes from the child's `close`: code 130 when `stopping`, and otherwise the code as today. `stopping` resets at the next start.
  - **`close()`.** While a child runs, `close()` stops it the same way and waits for its `close`, at most 3 s. Then it ends the subscribers, closes the server and removes the temp folder.

### Prompt (canonical)

Let a browser drive `devos init` safely, without forking the flow:
- a **plan** (every answer, as JSON) feeds the same code the terminal uses;
- the run's few prompts announce themselves with machine-readable markers;
- a local server, reachable only from this computer with a per-run token, starts the run, streams its progress, relays the developer's answers and keys, and can stop it.

The terminal flow behaves exactly as today.

### Stage 3 — the local server (proves D1 for (g)–(n), D3)

- **S6 — `lib/ui-server.mjs`.** It exports `startUiServer({ folder, port = 0, token })` and resolves `{ url, port, token, close }`.
  - **Network.**
    - Listen on `127.0.0.1` only.
    - The token defaults to `crypto.randomBytes(24).toString("base64url")`.
    - `url` is `http://127.0.0.1:<port>/?t=<token>`.
  - **Every request is checked:**
    - `Host` must equal `127.0.0.1:<port>`, or the response is 403 `{"error":"host"}`. This blocks DNS rebinding.
    - Every request that is not a GET must carry `Origin: http://127.0.0.1:<port>`, or the response is 403 `{"error":"origin"}`.
    - Every `/api/` request must carry `X-DEVOS-Token` equal to the token, compared with `crypto.timingSafeEqual` on equal-length buffers, or the response is 401 `{"error":"token"}`.
    - These three checks run in that order, before any body is read (FIX 4).
    - A JSON body may be at most 24 MiB (eight 2-MiB attachments in base64), or the response is 413. A body that is not a JSON object is 400 (FIX 2).
    - The whole handler runs in one `try`/`catch`: an error answers 500 `{"error":"internal"}` and is never printed.
  - **Every response carries these headers:**
    - `Cache-Control: no-store`;
    - `X-Content-Type-Options: nosniff`;
    - `Referrer-Policy: no-referrer`;
    - `Content-Security-Policy: default-src 'self'; connect-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; frame-ancestors 'none'`.

    Never send an `Access-Control-Allow-Origin` header.
  - **Routes:**
    - **`GET /`** (needs `?t=` equal to the token, otherwise 401) serves a placeholder page, `<!doctype html><title>DEV_OS</title><p>The guided setup page arrives in E22b.</p>`.
    - **`GET /api/state`** returns `{ contract, contractVersion, folder, empty, doctor: { ok }, agents: detectAgents() (no secrets), catalogue: { types, stacks, modules, documents }, defaults: <engine defaults agents>, visibility }`.
    - **`POST /api/plan`** takes the plan with `attachments: [{ name, base64 }]`:
      - at most 8 files, each at most 2 MiB decoded;
      - each name a plain file name: no `/`, `\` or `..`.

      It writes the files to a private temp folder (created again if a past run removed it), then runs `validatePlan`. It answers 200 `{ ok, summary: [lines], keys: [{ name, where, optional, file }] }`, or 400 `{ ok:false, errors }`. Only one plan is held. A plan after a `done` first clears the events (FIX 1).
    - **`POST /api/start`** (409 when no valid plan or a run is active):
      - writes the plan to the temp folder;
      - spawns `process.execPath bin/devos.mjs init --plan <file> <folder>` with `DEVOS_UI=1`, and pipes stdin and stdout;
      - answers 202.
    - **`GET /api/events`** is Server-Sent Events of `{"type":"log","text"}`, `{"type":"ask",…}`, `{"type":"step",…}` and `{"type":"done","code"}`. A late subscriber first receives every event so far. It needs the token header like every `/api/` route, so E22b reads it with `fetch` streaming: `EventSource` cannot send headers.
    - **`POST /api/answer`** takes `{ kind, value }` and is 409 unless the last unanswered ask has that `kind`:
      - `approve`: `value` is `"approve"`, or a change request of one line or more;
      - `key`: `value` is the key, or `""` to skip;
      - `create`: `"yes"` or `"no"`.

      The value is written to the child's stdin followed by `\n` and never kept or logged. A file key's `value` is base64 JSON. It is sent as the line `base64:<value>`, and no file is written (FIX 3). Answers 204.
    - **`POST /api/stop`** stops the run as FIX 5 says, and answers 204. It answers 409 when no run is active. The `done` event, code 130, comes when the child closes.
  - **On close or after `done`,** delete the temp folder.
- **S7 — `devos ui [folder]`.**
  - It starts the server and prints `DEV_OS setup: <url>`.
  - Unless `--no-open` is given, it opens the URL with the platform opener (`cmd /c start ""`, `open`, `xdg-open`), with no shell string built from user data.
  - It runs until Ctrl-C.
  - Add the usage line `devos ui [folder] [--no-open]`.
