#### Steps

### Stage 1 — the server picks no folder until the page names one (proves D1 for (s))

- **S1 — `lib/ui-server.mjs`.**
  - **`startUiServer({ folder })`.** `folder` may be `null`. When it is a non-empty string, the folder is fixed as today (`path.resolve`). Otherwise the server starts with no folder: *choose mode*.
  - **`GET /api/state`.**
    - `folder` is the current folder, or `null` until a plan names one.
    - `empty` is `folderEmpty(folder)`, or `true` while there is none.
    - New: `choose` (`true` in choose mode) and `suggest`: `path.join(os.homedir(), "devos-projects")` in choose mode, otherwise `null`.
  - **`POST /api/plan`.** Right after the JSON-object check:
    - **In choose mode,** `payload.folder` must pass these rules in order. Each refusal answers 400 `{ ok:false, errors:[<sentence>] }`:
      - a non-empty string, else `Choose a folder for the project.`;
      - `path.isAbsolute`, else `The project folder must be a full path.`;
      - after `path.resolve`, not the engine folder (`engineRoot()`) or inside it, else `The project folder cannot be inside the engine's folder.`;
      - if it exists, an empty directory, else `That folder already has files. Choose a new folder.`
    - **In both modes,** remove `folder` from the payload before the plan is held or written.
    - **When the plan validates,** the run's folder becomes the chosen one: `/api/state`, `/api/start` and the `init --plan` command line use it. A later plan may choose again.
  - **`uiCommand(args)`.** The folder is the first argument that is not `--no-open`, resolved, or `null` when there is none (no longer `process.cwd()`). After `DEV_OS setup: <url>`, print `Keep this window open until the setup is done. Ctrl+C stops it.`
- **S2 — Test (s)** in `test/ui-server.test.mjs`: a worker named `s`, like (o).
  - **The plan** comes from a separate stage. The server starts with `folder: null`.
  - **`/api/state`** gives `folder: null`, `choose: true`, and an absolute `suggest` whose basename is `devos-projects`.
  - **Each of these plans gives 400** with its sentence: no `folder`, `"relative/app"`, `<engine>/inside-app`, and the terminal stage's project folder (it has files).
  - **`<planned.parent>/chosen/my-app`** gives 200. `/api/state` then has that `folder`.
  - **`/api/start`** gives 202. At `ask approve`, `<that folder>/devos/project.json` exists. Stop the run.
