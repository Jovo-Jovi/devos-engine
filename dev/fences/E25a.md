- **What the copies change,** for the report:
  - **The runner (payload).**
    - `scripts/devos/lib.mjs`: `config()` applies three repository variables through the new
      `withModelOverrides(cfg, env)`:
      - `DEVOS_REVIEWER_MODEL` (the reviewer);
      - `DEVOS_REVIEWER_LIGHT_MODEL` (the light reviewer, made from the reviewer's tool when the project has none);
      - `DEVOS_BUILDER_MODEL` (the pool's default builder).

      Each keeps its role's tool. An empty variable changes nothing, and a value that is not a model id is ignored,
      with a note.
    - `scripts/devos/agents.mjs`: `pick` and `reviewer` add that note to `builder_note`, and to the new
      `reviewer_note`.
    - `devos-cycle.yml` (`resolve` and `cycle`), `devos-intake.yml` (`intake` and `revise`), `devos-doctor.yml` and
      `devos-supervisor.yml`: each of these six jobs passes the three variables in its `env`.
    - `docs/method/AUTOMATION.md`: three variable rows and "Models, in practice". `docs/method/PRECEDENTS.md`: PR-63
      and "Live maximum: PR-63".
  - **The engine.**
    - `lib/models.mjs` (new) and `bin/devos.mjs`:
      - `devos models [folder]` shows the three roles and the variable that changes each one;
      - `devos models set <reviewer|light|builder> <model> [folder]` sets that variable with `gh variable set`;
      - `devos models reset <role> [folder]` removes it with `gh variable delete`.
      It reads `devos.config.json` and `git remote get-url origin`, and calls gh only. It never commits, and never
      reads or writes a key.
    - `lib/keys.mjs`: right after a tool's first key, `neededKeys` adds that tool's `_2` key as optional, with where
      to get it. Init (terminal and page) asks for it; Enter skips it.
    - Version 1.1.0 (`package.json`, `CHANGELOG.md` `## 1.1.0 — Unreleased`, README `Version \`1.1.0\``), the README's
      keys step, "After setup" and command table, and `tools/sources.mjs` (E25a on the 8 payload files).
  - **Tests.**
    - `test/models.test.mjs` (new), (a)–(e).
    - `test/harness.mjs`: the fake gh lists `STUB_VARIABLES` when it is set.
    - The key lists and prompts of `agents-kit` (v), `catalogue` (i), `continue` (j) and `setup` (s) and (u) include
      the `_2` keys.
    - `version`, `install` and `upgrade` move from 1.0.0 to 1.1.0.
