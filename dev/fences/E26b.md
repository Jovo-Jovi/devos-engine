- **What the copies change,** for the report:
  - **`lib/hub.mjs`:**
    - `actionFacts(state)` reads what the actions need:
      - the folder's branch (`git branch --show-current`);
      - the default branch (`gh api repos/<slug> --jq .default_branch`);
      - the engine version on GitHub (`devos/engine.lock.json` on that branch);
      - the open pull requests from `devos/upgrade-<engine>` and from `devos/connect`.
    - `decideActions(state, facts)` is pure. It says whether **upgrade**, **pull** and **connect** may run now, and
      why not. It enforces the following:
      - an engine older than the latest release is told to update first;
      - the upgrade needs the project on GitHub to be older than this engine, the folder to match GitHub, the
        default branch checked out, and no upgrade pull request open;
      - connecting needs this engine, the project on GitHub and the latest release to be the same version,
        `DEVOS_REPORTING` not on, and no link pull request open.
    - `hubActions(state)` returns the facts and the decisions.
    - `upgradeProject` runs this engine's `bin/devos.mjs upgrade` in the folder (`lib/upgrade.mjs`: a branch, a
      commit and a pull request).
    - `pullProject` runs `git pull --ff-only` in the folder.
    - `connectProject` works through the GitHub API, and the folder is not touched. It does these steps in order:
      1. reads `devos/answers.json` on the default branch;
      2. creates the branch `devos/connect` from it;
      3. commits `registry_link: true` and this engine's contract version there;
      4. opens a pull request;
      5. sets `DEVOS_REPORTING` to `on`.

      When GitHub's answers already record the link, it only sets the variable.

    Each of the three runs only when `decideActions` allows it.
  - **`lib/folder-picker.mjs`** (new). The browser cannot give a page a folder's full path, so the page server opens
    the system's own folder dialog:
    - on Windows, PowerShell's folder browser (`-EncodedCommand`);
    - on macOS, `osascript` `choose folder`;
    - on Linux, `zenity`, then `kdialog`.

    `pickFolder()` resolves `{ ok, folder }`, `{ ok: false, cancelled: true }` or `{ ok: false, error }`. It reads nothing
    in the folder, and nothing from the page reaches the command. `launchDialog` runs only a real program, never
    through a shell, and stops after 10 minutes.
  - **`lib/ui-server.mjs`:**
    - `POST /api/pick-folder` returns the chosen path. It opens one dialog at a time and answers 409 while another is
      open or a run is going. The dialog runner is a `startUiServer` option (`picker`), so a test gives its own.
    - `GET /api/hub` adds `actions` (`hubActions`) to its answer.
    - `POST /api/upgrade`, `/api/pull` and `/api/connect` follow the folder rules of `GET /api/hub`. They read the
      state and the actions again and run only what is allowed.
    - `/api/connect` also needs `{ accept: true, contract: <this engine's contract version> }`; without it, it refuses
      before any gh call.
    - All three answer 409 while a run is going. The token, Host and Origin checks apply as to every `/api/` route.
  - **`lib/ui/app.js`:**
    - *A project in another folder* gets **Choose a folder…**. The chosen path fills the field and is looked up as
      **Find it** does; pasting a path still works.
    - The Version row reads the project's version on GitHub too.
    - A **Version** section offers **Upgrade to <engine> by pull request** and **Bring this folder up to date**, or
      says why not when something is behind. It links an open upgrade pull request.
    - **Connect to the Control Tower** works in three steps:
      1. **Read the contract** shows this engine's contract;
      2. a box says "I have read the contract … and I want this project linked";
      3. **Connect by pull request** stays disabled until the box is ticked.
    - After an action, the page shows the result and reads the project again. It uses the existing components only;
      no CSS change.
  - **`README.md`** ("After setup") and **`CHANGELOG.md`** (`## 1.2.0 — Unreleased`): the folder dialog, the upgrade and
    the link.
