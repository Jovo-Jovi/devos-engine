  local branch, never pushed. No payload file changes, so no precedent and no manifest change. A project started
  with `devos init` behaves as before.

      10. everything the commit will hold is staged: `git add -A`, then `git add -f` of the held files, `CLAUDE.md`

      11. `run-all --write-baseline`, then the whole `run-all`, which must exit 0. The guards scan exactly what is
          staged;
      12. the baseline is staged, then the same checks run on `git diff --cached` against the base;
      13. one commit `DEV_OS adopt: <name> (engine <version>)`, with the project's git hooks off
          (`core.hooksPath` set to an empty folder, `--no-verify`), and the worktree removed. The DEV_OS files that
          the project's `.gitignore` leaves out are named.

      **What devos reads and writes in the worktree** goes through `plainFile`, which refuses a link, or a folder in
      a file's place.

      **Any failure after step 1** removes the worktree and the branch, and says so. That covers:
      - a thrown error (`try`/`catch`);
      - Ctrl-C or `SIGTERM` at any point (signal handlers that exit, and an `exit` handler). During a tool round,
        the round's own Ctrl-C handler stops the tool first.
