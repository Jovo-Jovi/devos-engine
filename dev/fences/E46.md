- **S4 — The local finish** (`lib/setup.mjs`). `finishSetup` calls the new `localSetup(folder, answers)` when
  `answers.cycle === "local"` (no keys, no gh). In order:
  1. `README.md` if missing: `projectReadme(answers)` (S5).
  2. `SETUP.md`: new `export function localSetupMarkdown(answers, tools)`, exactly:

     ```
     # <name> — setup on this computer

     DEV_OS's method runs on this computer: each task is built in your IDE from its fence, on its own branch, and reviewed before it is merged. Nothing here needs GitHub's automated cycle.

     ## 1. Tools

     - Node.js 22 or newer, and git.
     - <label> (`<command>`), signed in.            ← one line per agent tool, reviewer first, then the pool's

     ## 2. The app's own keys

     In `.env.local`, never committed: `<NAME>`, `<NAME>`.      ← or `None.` without app keys

     ## 3. Add a GitHub backup later

     The workflows are installed, and none runs until the project is on GitHub. To keep only `ci.yml` there:

     1. `gh repo create <your account>/<key in lower case> --private --source . --remote origin`
     2. `gh variable set DEVOS_PAUSED --body true --repo <your account>/<key in lower case>`
     3. `git push -u origin main`
     ```

     The labels and commands come from `lib/data/tools.json`, and the app keys from `catalogueAppKeys`.
  3. `git init -b main` when `.git` is missing, `git add -A`, and the commit `DEV_OS bootstrap: <name>`. These are the
     same calls and `stopped(...)` lines as `completeSetup`.
  4. **Local tools.** Every agent tool must be `installed` and `signedIn` in `detectAgents()`. A missing one prints
     `devos: <label> is not installed or not signed in on this computer; sign in, then run devos continue <folder>`

  5. **The GitHub backup.** It asks
     `Also create a private GitHub repository as a backup? Only CI runs there; DEV_OS stays on this computer.`
     (`confirm`, default no).
     - **No:** nothing more.
     - **Yes:** `doctorCommand()` (the GitHub doctor). If it fails, it prints
       `devos: no GitHub backup now; SETUP.md §3 has the three commands for later`, and goes on. Otherwise:
       - the owner comes from `profileOwner()`, else `gh api user --jq .login`;
       - then `gh repo create <slug> --private --source . --remote origin`, where `<slug>` is
         `repoSlug(owner, answers)`;
       - then `gh variable set DEVOS_PAUSED --body true --repo <slug>`;
       - then `git push -u origin main`, in that order;
       - it prints `devos init: backup on GitHub: <slug> (only ci.yml runs there; DEVOS_PAUSED is true)`.

       A failed call prints the call's own error and
       `devos: the backup stopped; SETUP.md §3 has the steps`, and goes on: the local project is complete.
  6. It prints `devos init: <folder> is set up on this computer; build T01 in your IDE from docs/fences/T01.md on the branch task/T01` and returns
