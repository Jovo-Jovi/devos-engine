### What the package does

- **1. The bypass secret is advised only where it is sent (PR-98).**
  - **When the secret is sent:** the deploy's smoke test, the doctor and the screenshots send
    `VERCEL_AUTOMATION_BYPASS_SECRET` only when `deploy.bypass` is true. With it false, the doctor already says "No
    bypass secret is added", and `AUTOMATION.md` §8 says such a project has none.
  - **The change:** the setup item `vercel-bypass` (recommended, blocks nothing) gets a new condition, `bypass:true`,
    in `setup-check.mjs` and in `lib/setup.mjs`.
  - **Effect:** with the default (false), the item is not listed at all, so a new project's `SETUP.md` has four Vercel
    headings, not five. The keys the cycle asks for do not change: they never included this secret, since it blocks
    nothing.
- **2. Claude Fable 5.2.**
  - **The model:** `claude-fable-5-2`, released 2026-11-09; it is the model ID on the Claude API.
  - **The change:** it goes first in the Claude group of Claude Code's list and of Cursor's.
  - **Cursor:** its CLI lists its own models (`agent models`), so a Cursor account shows Fable 5.2 under the name
    Cursor gives it.
  - **Defaults:** they stay on Claude Opus 5.5 and Sonnet 5.5. Anthropic's guide says to start with the latest Opus
    and move to Fable when evaluations at higher effort fall short.
- **Records:** the CHANGELOG entry `1.13.7 — Unreleased`; version 1.13.7 in `package.json`, `README.md` and
  `payload/manifest.json`; the tests that name the version (the upgrade scenarios now go from 1.13.7 to 1.13.8).
