### Why these choices

- **Strip, then deny.** No Cursor setting turns off a workspace's hooks, so the review's copy never has them. Deny
  rules cover what the agent could write during the run.
- **Claude Code's step is untouched.** Its call, flags and settings are as PR-90 left them. Only its `if:` names the
  tool.
- **Codex and Gemini are refused, not guessed.** Nobody signed in to either has run the check. Each becomes a review
  tool once `review-check` passes for it.
- **Owner attention.** Planning a request, a method fix or a revision still needs Claude Code as the reviewer
  (PR-92). A Cursor-reviewed project plans on Claude Code once E85 lets the planner have a tool of its own.
