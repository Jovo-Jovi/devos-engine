### The change

1. **The review job keeps the developer's configuration.**
   - The reviewer step sets `DEVOS_BUILDER_MODEL: ${{ vars.DEVOS_BUILDER_MODEL }}`, as every other job does.
   - The attempt's builder model goes to the prompt alone, as `DEVOS_BUILT_MODEL: ${{
     steps.prep.outputs.builder_model }}`.
   - `render-prompt.mjs` reads `DEVOS_BUILT_MODEL`, then `DEVOS_BUILDER_MODEL`, then the default builder's model.
   - `config()` (PR-63) is unchanged: `DEVOS_BUILDER_MODEL` still makes the default builder's model.
2. **Every non-Claude run of `plan-agent.sh` gets its whole prompt.**
   - The prompt with its answer section is written to `.devos/<stage>-answer-prompt.md`, never over the prompt it is made
     from.
   - Cursor's line names that file: `Your instructions for this run are in the file .devos/reviewer-answer-prompt.md. …`.
   - Codex and Gemini read it on standard input.
   - This applies to the review job, intake and revise.
3. **The progress line ends with its sleep.**
   - The 5-minute loop runs `sleep 300 & s=$!; wait "$s"` under a `trap` that kills the sleep on `TERM`.
   - The step runs `kill "$hb"`, then `wait "$hb"`.
4. **PR-103** in `PRECEDENTS.md` (live maximum PR-103); the `plan-agent.sh` row of `AUTOMATION.md` names
   `.devos/<stage>-answer-prompt.md` and `DEVOS_BUILT_MODEL`; `CHANGELOG.md` 1.13.18; the version 1.13.18 in
   `package.json`, `README.md`, the manifest and the six tests that name it.
5. **Tests:**
   - `review-job.test.mjs` (c) expects Cursor's line to name `.devos/reviewer-answer-prompt.md`;
   - `chosen.test.mjs` (d) expects `.devos/intake-answer-prompt.md`;
   - the new `review-job.test.mjs` (g) runs the reviewer step's own script with a review-only run's environment, on a
     pool of Cursor models whose names pin their effort, and checks that:
     - the step ends in under a minute with `reviewer: cursor grok-4.7-xhigh, exit 0, limited false, permission
       denials 0`;
     - the rendered prompt lists the configured pool;
     - the file Cursor was told to read starts with the whole rendered prompt and ends with the answer section;
     - with `DEVOS_BUILDER_MODEL=unknown` the step still stops as the runs did. On main's files, (g) fails, and with
       only point 1 applied it fails on the emptied prompt;
   - `hardening.test.mjs` (g) expects the review job's two lines, `DEVOS_BUILT_MODEL` from verify's trusted ids and
     `DEVOS_BUILDER_MODEL` from `vars`.

18 files in all. Nothing changes for a project's configuration, and `devos upgrade` asks no question.
