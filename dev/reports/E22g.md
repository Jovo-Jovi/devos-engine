What the copies change:

- A quiet round stops itself (`lib/init.mjs`). The limit is 15 minutes, or `DEVOS_IDLE_LIMIT_MS`. It means no output from the agent and no file changed in the project (`.git`, `node_modules`, `.devos`, `.next`, `dist` and `build` left out). The engine prints `devos: <command> made no progress for <span> (last step: …); the round was stopped`. A round stopped this way or by the hour, whose `docs/PHASES.md` exists, goes to the checks. If they pass, it prints `devos: the documents it wrote pass the checks; review them` and asks for the review. Otherwise a repair round follows.
- The session is kept. Each round's agent session goes to `.devos/blueprint-session.json`. `blueprintArgs` gains `follow`, so a repair can carry on that session (`--resume <id>` for Cursor, `--continue` for Claude Code).
- `resumeBlueprint` checks a written blueprint before it drafts anything. Passing documents go straight to the review (`devos: the blueprint is written and passes its checks; review it`). Failing ones get one repair round (`devos: the written blueprint fails these checks:`). With no `docs/PHASES.md`, the whole blueprint runs as before.
- The server (`lib/ui-server.mjs`). An accepted plan's choices go to `~/.devos/choices.json` (`rememberChoices`): the agents, the blueprint agent, the type, stack, modules and scope, the languages, the visibility, and the folder that holds the projects. They never include a key or the project's name, brief or users. `/api/state` returns them as `choices`. `/api/project` returns the project's saved `choices` (`savedChoices`).
- The page (`lib/ui/app.js`). A new start begins from the remembered choices (`withRemembered`), keeping only what this computer and the catalogue still offer. A continued project shows its own choices (`withChoices`). The page does not use `localStorage`.
- The README gains the quiet-round stop, Continue on a written blueprint, and the kept choices.
