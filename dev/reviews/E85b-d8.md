The causes, both in E85's payload, each reproduced in a test (`review-job.test.mjs` (g)):
1. **The review job put the attempt's model into the developer's variable.**
   - The reviewer step sets `DEVOS_BUILDER_MODEL` from verify's builder tags. A review-only run has none, so the value
     is `unknown`.
   - `config()` makes `DEVOS_BUILDER_MODEL` the default builder's model (PR-63). learn-coptic's pool names Cursor
     models whose effort is in the name (`grok-4.7-xhigh`), so they carry no `effort`. `unknown` has no effort in its
     name, so PR-99's check stopped the run.
   - On main's own files, `missingChoices` finds nothing missing, and the prompt renders.
2. **Every Cursor, Codex or Gemini run of `plan-agent.sh` got only its answer section.** The reproduction found this.
   - `plan-agent.sh` writes the prompt plus its answer section to `<base>-prompt.md`. The callers pass
     `.devos/<stage>-prompt.md`, which is that same file, so the shell empties it before `cat` reads it.
   - The review job, intake and revise all name their prompt that way. Claude Code takes a schema and never reaches
     this code.
   - So E85's D8 review (74 minutes on Cursor, `dev/reviews/E85-d8.md`) ran with no review instructions in its prompt:
     only its kit's rules, the files, and the answer schema.
3. **The progress line held the step open.** E85b's 5-minute line left its `sleep` running after the reviewer
   finished, holding the step's output. The old loop, piped to a reader, held it until the 8-second cap of the
   reproduction.
